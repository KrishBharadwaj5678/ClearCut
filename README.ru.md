# 🎬 Четкий разрез

**Четкий разрез** это Python-скрипт, который удаляет фон в реальном времени с помощью веб-камеры. Он позволяет бесшовно заменять фон во время прямой трансляции с камеры.

![Четкий разрез](https://github.com/KrishBharadwaj5678/ClearCut/raw/main/ClearCutDemo.png)

## 🌟 **Функции**

| Функция                                 | Описание                                                      |
| --------------------------------------- | ------------------------------------------------------------- |
| 🎥 **Удаление фона в реальном времени** | Мгновенно удаляет фон во время работы веб-камеры              |
| 🤖 **Модуль SelfieSegmentation**        | Использует SelfieSegmentation для высокого качества обработки |
| ⌨️ **Управление с клавиатуры**          | Нажмите **A** для предыдущего фона и **D** для следующего     |
| ⚡ **Лёгкий и быстрый**                  | Оптимизирован для низкой задержки                             |
| 💻 **Работает с любой веб-камерой**     | Совместим с большинством камер                                |
| 🛠️ **Простая установка**               | Минимум зависимостей                                          |
| 🌍 **Кроссплатформенность**             | Работает на Windows, macOS и Linux                            |

## 🛠️ **Установка**

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/ClearCut.git
```

### 2️⃣ Переход в папку

```bash
cd ClearCut
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
python app.py
```
