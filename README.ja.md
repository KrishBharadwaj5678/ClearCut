# 🎬 クリアカット

**クリアカット** は、ウェブカメラを使用してリアルタイムで背景を削除する Python スクリプトです。ライブ映像配信中でも、背景をシームレスに置き換えることができます。

![クリアカット](https://github.com/KrishBharadwaj5678/ClearCut/raw/main/ClearCutDemo.png)

## 🌟 **機能**

| 機能                              | 説明                      |
| ------------------------------- | ----------------------- |
| 🎥 **リアルタイム背景除去**               | ウェブカメラ映像から即座に背景を削除      |
| 🤖 **SelfieSegmentation モジュール** | 高品質なセグメンテーションを実現        |
| ⌨️ **キーボード操作**                  | **A** で前の背景、**D** で次の背景 |
| ⚡ **軽量・高速**                     | 低遅延で動作するよう最適化           |
| 💻 **任意のウェブカメラ対応**              | ほとんどのカメラと互換性あり          |
| 🛠️ **簡単セットアップ**                | 最小限の依存関係で導入可能           |
| 🌍 **クロスプラットフォーム**              | Windows、macOS、Linux 対応  |
