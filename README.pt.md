# 🎬 Corte Claro

**Corte Claro** é um script em Python que remove o fundo em tempo real usando a webcam. Ele permite substituir o fundo de forma contínua enquanto você transmite ao vivo pela câmera.

![Corte Claro](https://github.com/KrishBharadwaj5678/ClearCut/raw/main/ClearCutDemo.png)

## 🌟 **Funcionalidades**

| Funcionalidade                        | Descrição                                                    |
| ------------------------------------- | ------------------------------------------------------------ |
| 🎥 **Remoção de fundo em tempo real** | Remove o fundo instantaneamente durante o uso da webcam      |
| 🤖 **Módulo SelfieSegmentation**      | Usa o SelfieSegmentation para resultados de alta qualidade   |
| ⌨️ **Controles do teclado**           | Pressione **A** para o fundo anterior e **D** para o próximo |
| ⚡ **Leve e rápido**                   | Otimizado para baixa latência                                |
| 💻 **Funciona com qualquer webcam**   | Compatível com a maioria das webcams                         |
| 🛠️ **Configuração simples**          | Instalação fácil com poucas dependências                     |
| 🌍 **Multiplataforma**                | Funciona no Windows, macOS e Linux                           |

---

## ⚙️ **Tecnologias Utilizadas**

| Tecnologia       | Descrição                                 |
| ---------------- | ----------------------------------------- |
| 🐍 **Pitão**    | Linguagem principal do script             |
| 🖥️ **OpenCV**   | Usado para captura de vídeo em tempo real |
| 🎯 **Zona CV**    | Simplifica tarefas de visão computacional |
| 🤖 **MediaPipe** | Fornece segmentação em tempo real         |

## 🛠️ Instalação

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/ClearCut.git
```

### 2️⃣ Entrar na pasta

```bash
cd ClearCut
```

### 3️⃣ Instalar dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar o aplicativo

```bash

```
